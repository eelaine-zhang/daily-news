英伟达 · CPU

英伟达发布首款自研 CPU "Vera"——从 GPU 公司变身为全栈 AI 计算平台

英伟达在 ISC 2026 上发布 Vera 数据中心 CPU，基于自研 Olympus ARM 核心，88 核、1.2TB/s LPDDR5X 带宽。核心卖点不是"核心多"，而是"单线程快"——称比 x86 处理器在 AI Agent 工作负载下快 1.8 倍。Perplexity 已在测试中，代码沙箱启动快 1.9 倍。Vera 既是 AI Agent CPU，也是 Vera Rubin 超算系统的主机 CPU，还用于 BlueField-4 存储处理器——一芯三用。

🦞 为什么值得看：这是英伟达战略的重大转向——从"卖 GPU"变成"卖整个 AI 工厂"。之前 CPU 是 Intel/AMD 的地盘，英伟达只做加速卡。现在 Agent 时代来了，Agent 的"思考"过程（工具调用、代码执行、数据处理）跑在 CPU 上，GPU 只在模型推理时才忙。如果 CPU 慢，GPU 就在空等——Vera 的逻辑是"让 CPU 不拖 GPU 后腿"。对 Intel/AMD：这是直接的 CPU 市场入侵，英伟达在抢 $2000 亿 CPU 大盘。
📌 关联标的：NVDA（受益）、INTC/AMD（受损）— 英伟达从 GPU 延伸到 CPU，全栈化战略进一步挤压传统 CPU 厂空间
来源：DataCenter News · HPCwire · FourWeekMBA

Apple · CXMT

Apple 开始测试中国 CXMT DRAM 芯片——供应链多元化的"谈判牌"

FT 报道：Apple 已开始测试中国国营存储厂长鑫存储（CXMT）的 DRAM 芯片，计划用于中国市场的设备，同时正游说白宫批准更广泛使用。Apple 还在与 YMTC（长江存储）谈判 NAND 采购。背景：2026 年 DRAM 合约价暴涨 55-60%，Apple 已因此全线提价 iPad/Mac。CXMT 目前全球第四大 DRAM 厂，约占 11% 产能，预计 2028 年达 15%。Bank of America 认为 Apple 用 CXMT 主要是增加与三星/SK Hynix/Micron 谈判的筹码。

🦞 商业含义：这是一个教科书级的"供应链博弈"案例。Apple 的逻辑是：① DRAM 涨太猛，需要替代源压价；② 中国市场设备的供应链本土化是合规+成本双优；③ 即使最终不大量采购，测试本身就能让三星/Hynix 紧张。但风险是：CXMT 在美国实体清单上，政治风险高。CXMT 同时在合肥试验 W2W 混合键合技术——如果跑通，AI 高密度内存领域可能出现"中国路线"。
